## 🧑‍💻 Sobre Mí
Soy un desarrollador de software apasionado por la tecnología en todas sus capas: desde las líneas de código que dan vida a un programa hasta los componentes físicos que lo hacen posible. Cuento con un perfil versátil que combina la lógica del desarrollo de software con la destreza técnica del mantenimiento, ensamble, desarme y optimización de equipos de cómputo (PCs de escritorio y portátiles).

* **Desarrollo de Videojuegos:** Unity Engine, C#, Programación Orientada a Objetos (POO).
* **Soporte Técnico:** Diagnóstico de fallas, mantenimiento preventivo/correctivo, ensamble de componentes y optimización de hardware.
* **Herramientas de Despliegue:** Git, GitHub, GitHub Pages.
